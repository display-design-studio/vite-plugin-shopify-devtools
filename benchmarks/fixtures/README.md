# Inference fixtures

These deliberately small, store-data-free fixtures retain only markup needed to exercise inference. They are adapted from:

- Dawn at `258f00f64365e2018ca4c62778a6bf55a5d3cd18` (Shopify, MIT).
- Horizon at `5acd1b6b66c02f61d3216e3adace5dd9e0404fc9` (Shopify, MIT).
- Skeleton Theme at `a4f32d393b9eadf6c4403318ca39116832e5d1df` (Shopify, MIT).

Each theme has home, product, and collection HTML snapshots plus the minimal Liquid and JSON subset required by `resolveSections`. The snapshots contain no merchant or customer data.
