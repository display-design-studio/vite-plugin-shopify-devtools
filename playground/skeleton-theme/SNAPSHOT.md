## Local changes

Vite is set up like the [Display starter](https://github.com/display-design-studio/skeleton-theme), with one CSS and one TS entrypoint:

- `frontend/entrypoints/css/main.css` and `frontend/entrypoints/ts/theme.ts`, rendered through `vite-tag` in `layout/theme.liquid` and `layout/password.liquid`.
- `vite.config.js` registers `vite-plugin-shopify` and `@display-studio/vite-plugin-shopify-devtools`, with `@ts` / `@css` aliases.
- `package.json` depends on the plugin via `file:../..` and runs `shopify-devtools dev`.
- `sections/inference-demo.liquid`, the `demo-*` snippets and two entries in `templates/index.json` (`demo`, `theme_blocks`) exercise the inferred tree: nested and repeated snippets, markup shared by two snippets, a snippet with no element, inline blocks and nested theme blocks. `test/inference.test.ts` renders them with LiquidJS and scores the inference against marker output.
- `snippets/vite-tag.liquid` and the built `assets/*.js` / `assets/main-*.css` are generated by Vite and gitignored.

## Setup

```sh
cd ../..
bun install
bun run build
cd playground/skeleton-theme
bun install
echo "SHOPIFY_STORE_DOMAIN=your-store.myshopify.com" > .env
printf '[environments.development]\nstore = "your-store.myshopify.com"\n' > shopify.theme.toml
bun run dev
```

## Trying the inferred tree

Default mode (the plugin alone, no wrapper): run `bun run vite:dev` and `bun run shopify:dev` in two terminals and open the **demo** and **theme_blocks** sections on the home page. Blocks and snippets show up as `inferred`.

Full mode (exact markers): stop both and run `bun run dev`, then in the browser console run `await shopifyDevtools.compareInference()` to see how many snippets and theme blocks the inference finds compared with the markers.
